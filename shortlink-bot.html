ShortLink Bot

A Telegram bot that converts submitted links into your connected URL shortener, with configuration and admin features included.

Link shortening

Convert links through a connected custom URL shortener with a simple Telegram interface.

BOT FEATURES

Admin & access tools

Includes auth-channel support, log-channel support, broadcast functionality and user statistics.

Multiple platforms

The repository documents deployment options including Heroku, Koyeb, Render and Railway.
